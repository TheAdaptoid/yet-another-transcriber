# Design references

Yet Another Transcriber uses a restrained Neo-Brutalist language for its small
Windows dictation indicator. Clear state words and dependable controls come
before decoration: this overlay appears over another app while the user works.

- [Neo-Brutalist design language](neo-brutalism.md): reusable color, type,
  structure, interaction, and motion rules.
- [Dictation indicator](indicator.md): the shipped four-state implementation,
  diagram, actions, and Windows-specific constraints.

These references describe the Tk implementation, not the earlier HTML studies.
When changing a visual surface, verify its rendered Windows behavior and update
the references if the rules change. The approved
[indicator specification](../superpowers/specs/2026-11-17-neo-brutalist-dictation-indicator-design.md)
explains the design decision and boundaries.
